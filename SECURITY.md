# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

pyfloor is a read-only, dependency-free audit tool, so the attack surface is
small. Still, if you find a security issue, please report it privately rather
than opening a public issue.

Email the details to **anas@0xshaikh.dev**. Please include:

- The affected version(s).
- A description of the vulnerability.
- A minimal reproduction (command, input tree, expected vs. actual behavior).
- Whether you consider it exploitable and under what conditions.

Do not include real credentials or private project data in the report.

## What to expect

- An acknowledgment within 3 business days.
- A proposed fix or a triage decision within 14 days.
- Credit in the release notes and, if you wish, in the changelog.

## Known issues

There are no known security issues at this time.
