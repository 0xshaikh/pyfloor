# Privacy Policy

This site -- the pyfloor project documentation at
`https://0xshaikh.github.io/pyfloor/` -- is a **static site**.

It collects nothing, tracks nothing, and sets no cookies. There are no
analytics scripts, no advertising, no third-party trackers, and no
server-side logging of your visit. The only network requests your
browser makes are to fetch this page and its static assets (images,
favicon) from the same static host.

If you install or use the pyfloor command-line tool itself, it runs
entirely on your machine, reads only the project files you point it at,
and performs no network calls.
